## M2 Validation — BLAKE3 Embed Cache

Cold vs warm same batch (500 docs):
- Cold: 1783 ms (embed 500 texts on CPU)
- Warm: 1.4 ms (all BLAKE3 hits, zero compute)
- **Speedup: 1,273×**

Cache file: `redb` single-file, keyed on `BLAKE3(text)`, value = 384 × f32 LE.
Survives daemon restart.

## M7 ANE — Status

fastembed 5 does not expose ONNX Runtime EP configuration. To enable Apple Neural Engine:

1. Fork fastembed to expose `InitOptions::execution_providers(CoreMLExecutionProvider::default().build())`, OR
2. Implement our own minimal tokenizer + ort session (bypass fastembed).

Projected ANE gain from ort docs: 3-5× single-thread, up to 10× batch on M4. Would push cold embed from 280 docs/s to 800-2800 docs/s, closing the gap to SQLite-only targets.

Tracked as ongoing work (not MVP blocker — cache path already delivers 1273× on repeat text).
